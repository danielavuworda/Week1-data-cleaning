# Week1-data-cleaning
# Week 1: Data Cleaning and Exploration

## Project Overview

This project focuses on cleaning and exploring an applicant dataset using Python and Pandas.

## Objectives

* Identify missing values.
* Detect and remove duplicate records.
* Standardize text fields and domain categories.
* Convert application dates to appropriate data types.
* Standardize phone-number formatting.
* Produce a cleaned CSV file.
* Document the data-cleaning process.

## Tools Used

* Python
* Pandas
* NumPy
* Google Colab
* GitHub

## Project Files

* `Week1_Data_Cleaning_YourName.ipynb`: Documents the cleaning process and analysis.
* `applicants_cleaned.csv`: Contains the cleaned applicant dataset.
* `applicants.csv`: Original dataset, if included.

## Reproducibility

The notebook contains the code and explanations required to reproduce the cleaning process from the original dataset.
